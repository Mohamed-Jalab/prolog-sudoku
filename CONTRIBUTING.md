# Contributing

Thank you for helping improve Prolog Sudoku.

## Development workflow

1. Fork the repository and create a branch for your change.
2. Keep changes focused and use clear commit messages.
3. Add or update tests when behavior changes.
4. Run the full test suite:

   ```bash
   swipl -g run_tests -t halt test_sudoku.pl
   ```

5. Open a pull request explaining what changed and why.

Please keep discussions respectful and never include private information,
credentials, or generated build files in an issue or pull request.
